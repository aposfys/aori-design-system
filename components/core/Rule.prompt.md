Use `Rule` to divide a page. The system has three line weights and no others.

```jsx
<Rule />
<Rule weight="hair" spacing="var(--space-4)" />
<Rule weight="brush" color="var(--pigment-red)" />
```

- `hair` (1px stone) for ledger and metadata divisions; `ink` (2px carbon) for section breaks; `brush` (3px) once per page at most.
