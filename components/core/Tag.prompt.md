Use `Tag` for the short factual labels the voice depends on — material, run size, collection name.

```jsx
<Tag>18k Gold</Tag>
<Tag variant="solid" pigment="var(--pigment-water)">Livyko</Tag>
<Tag variant="ledger" size="sm">Run of 12</Tag>
```

- `ledger` drops out of the uppercase voice into the body serif — use it inside sizing, shipping and order tables.
- Never use a Tag for an action. That is `Button`.
